this project is to investigate a simulated Windows workstation and identify, analyze, and document evidence related to suspicious activity.

## 🔎 Investigation Scope

This project will investigate:

- Windows Event Logs
- PowerShell activity
- Process execution
- Registry artifacts
- File-system activity
- Browser artifacts
- USB activity
- Timeline reconstruction

## 🧪 Environment

- Operating System: Windows
- Investigation Type: Simulated forensic investigation
- Evidence: Authorized lab/synthetic evidence

## 🔬 Methodology

The investigation will follow these general stages:

1. Identify the evidence
2. Preserve the evidence
3. Collect relevant artifacts
4. Analyze the artifacts
5. Build a timeline
6. Correlate findings
7. Document the investigation
8. Produce a final report
